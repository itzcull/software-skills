# Structured-development examples

Use this catalogue to select examples relevant to a comparison or unresolved design choice. Read only the examples needed; each contains its sources, responsibility mappings, loop and concern analysis, and evidence limits.

[SKILL.md](../SKILL.md) defines the contract. Inclusion here does not certify conformance. Use its [source-evidence labels](../SKILL.md#researched-examples) when reading mappings and the [evaluation framework](../references/evaluating-procedures.md) when assessing a procedure or proposing model changes.
